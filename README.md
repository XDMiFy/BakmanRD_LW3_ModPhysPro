
# BakmanRD_LW3_ModPhysPro
Практическая Работа №3 Моделирование Физических процессов Бакман Роман

<img width="720" height="450" alt="demo" src="https://github.com/user-attachments/assets/42e37ebf-a4ac-41cb-a1cd-6a7d8f76ef2e" />


2D rigid body: CCD и multi-rate. Упрощённый движок AABB без вращения с тремя режимами

| Режим | Для чего нужен |
|---|---|
| `DISCRETE` | шаг 1/60 с, пересечения проверяются в конце шага (базовая линия, туннелирует) |
| `CCD` | шаг 1/60 с, момент удара ищется внутри шага (swept AABB, метод плит), затем остаток шага |
| `MULTIRATE` | обычные тела 60 Гц, снаряды 240 Гц |

## Сборка

Зависимости: CMake ≥ 3.16, компилятор C++20, SDL2.

## Клавиши

| Клавиша | Действие |
|---|---|
| `1` / `2` / `3` | DISCRETE / CCD / MULTIRATE (сцена перезапускается из того же состояния) |
| `Tab` | сцена: Стенка → Арена → Пирамида |
| `R` | перезапуск |
| `Space` / `N` | пауза / один шаг на паузе |
| `F` | выстрел снарядом (Арена, Пирамида); в Арене 5 снарядов и так вылетают сами на 1.0–3.0 с |
| `S` | вкл/выкл синхронизацию групп в MULTIRATE (`syncSlow`) |
| `Esc` | выход |

## Замеры

```bash
./build/ModPhysPro --bench
```

## Где что

- `config.h` — все параметры (e, скорость снаряда, частоты, толщина стенки, константы решателя)
- `physics.h` — тела, контакты и решатель, `sweptAABB`, три режима шага, сцены
- `main.cpp` — окно SDL2, клавиши, бенч
